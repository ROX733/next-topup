# Next TopUp

Mobile-friendly Next.js storefront and admin **prototype**.

## Run
`npm install && npm run dev`

## Deploy
Import this repository into Vercel with the Next.js preset.

## Important
No customer registration. Demo game/product data is in-memory and resets on refresh. Admin is not authenticated; this page is **not safe for real use**. UID verification, QR generation, payment collection and automatic fulfillment are disabled. Merchant Order ID is displayed in order details. Before launch, add a database, protected admin backend, verified UID API and payment gateway with server-side webhooks.
